# Patitas — Motor de Historiales Clínicos Veterinarios (`v0.1`)

Motor de gestión clínica desarrollado en **Node.js** para digitalizar y consultar los historiales médicos de los pacientes de la veterinaria **Patitas** (Lola, Toby, Mía y nuevos pacientes), garantizando inserciones, búsquedas y correcciones seguras sin fragmentar ni "cortar" la secuencia cronológica de atenciones.

---

## Cómo ejecutar el proyecto

No requiere dependencias externas ni instalación de paquetes (`npm install` no es necesario); funciona de forma nativa con **Node.js**.

1. Abre una terminal en la carpeta raíz del proyecto (`patitas-motor`).
2. Ejecuta el reporte general de pacientes y costos con el comando:

```bash
node src/reporte.js
